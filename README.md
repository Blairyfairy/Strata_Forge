# StrataForge
![StrataForge mark](assets/mark.svg)

Competitive Strategy & Product Scope Studio — Blair Page.

A standalone interactive product strategy sandbox for commercial building energy operations. Ratings and effort points are illustrative, not measured results. Explore positioning priorities, release capacity and feature dependencies. No original coursework files are distributed.

## Deploy
Upload the contents of this directory to a GitHub repository and enable Pages from the main branch root. No build or backend required.
